команды управления ботом:
/set_total 15 — задать количество 15 (кол-во задаётся от тех кто должен проголосовать и отправляет сколько не проголосовало от этого кол-ва)
/set_total 0 — не считать кто не проголосовал
/set_users @ivan @petr — задать список, чтобы отправлять username тех кто не проголосовал
/get_users — показать список username включенных в аналитику
/use_list — считать по списку 
/use_total — считать по количеству
/get_mode — текущий режим

-------------------------------------
config.py
POLL_TIME = "01:51" - задаёт время опроса
ANALYTICS_TIME = "01:52" - задаёт время аналитики опроса и когда аналитика отправится в чат
-------------------------------------
storage.txt
Список никнеймов в тг по которому бот будет анализировать и писать кто не отметился, а должен был
-------------------------------------
storage_total.txt
число которое указывает на кол-во людей которые должны были отметится, если кол-во отметившихся не набралось пишет сколько не хватает
-------------------------------------
storage_mode.txt
Может быть либо флаг total либо list - определяет какой режим будет использоваться для подсчёта тех кто не отметился
